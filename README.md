# Shopify Developer Lernpfad

Massgeschneiderter Kurs fuer Fullstack-Entwickler mit Odoo- & Next.js-Erfahrung.

## Kursuebersicht

| Modul | Thema | Issues | Dauer |
|-------|-------|--------|-------|
| 1 | Shopify Fundamentals | #1-#3 | 1 Woche |
| 2 | Liquid Template Language | #4-#6 | 1 Woche |
| 3 | Theme-Entwicklung | #7-#10 | 2 Wochen |
| 4 | Shopify CLI & Workflow | #11-#12 | 1 Woche |
| 5 | Shopify APIs | #13-#15 | 2 Wochen |
| 6 | Custom App-Entwicklung | #16-#19 | 2 Wochen |
| 7 | Hydrogen & Headless | #20-#22 | 2 Wochen |
| 8 | Abschlussprojekt | #23-#24 | 2 Wochen |

## Voraussetzungen

- JavaScript/TypeScript & React (Next.js) ✅
- REST & GraphQL APIs ✅
- Odoo E-Commerce Domain-Knowledge ✅
- Git & CLI ✅

## Arbeitsweise

1. Issues der Reihe nach bearbeiten (1→24)
2. Jeder Issue enthaelt Aufgaben-Schritte, Ressourcen & Akzeptanzkriterien
3. Code in dieses Repository pushen
4. Issue schliessen wenn alle Akzeptanzkriterien erfuellt sind

## Ziel

Nach Abschluss kannst du eigenstaendig Shopify Themes, Apps und Headless-Storefronts entwickeln.
